Calling Center

Calling Center helps teams call Lead Bank numbers one by one through MCube, capture mandatory outcomes, track call progress, and keep telecaller reporting clean.

Call TriggerAfter outcome submit
Calling ModeMCube outbound
Agent RoleTelecaller
Next Call Delay2 / 3 / 5 min

Purpose

The module is designed for controlled bulk calling. Admin or an authorized user creates a campaign from Lead Bank folders, assigns it to an agent, and MCube sends calls to that agent one at a time.

Bulk campaign calls are MCube-only. Browser tel: fallback is used only for normal manual single-call buttons.

Workflow

  1. Create campaign

    Select Lead Bank folder, filters, quantity, agent, delay, and retry policy.

  2. Start campaign

    The first eligible lead is picked and an MCube outbound call is initiated.

  3. Agent receives call

    The selected telecaller receives the call on their configured phone number.

  4. Submit outcome

    The agent must select an outcome before the system unlocks the next call.

  5. Next call starts

    After the selected delay, the queue processor starts the next pending call.

Campaign Features

Lead Bank Source

Create campaigns from All Lead Bank, Unassigned leads, or tag-based folders.

Filters

Filter leads by city, source, status, and search keyword before creating the campaign.

Delay Control

Choose immediate calling after outcome or use a delay like 2, 3, or 5 minutes.

Duplicate Guard

Duplicate leads and duplicate phone numbers are skipped inside the same campaign.

Lead Safety

Dead, junk, and not-interested leads are skipped by default to avoid wrong calling.

Export

Campaign call data can be exported with lead, status, outcome, duration, and recording columns.

Agent Queue

My Calling Queue Shows

  • Current campaign
  • Current lead and phone
  • Call status
  • Call start time
  • Upcoming calls

Mandatory Outcomes

Interested Not Interested Follow Up CNP Junk Meeting Request Site Visit Request

Roles And Access

Role Allowed Restricted
Admin Create, start, pause, cancel, report, export, and manage all campaigns. No default Calling Center restriction.
Telecaller Own queue, own outcomes, own reports, own recordings if enabled, attendance, and profile. Lead Bank inventory, import/export, integrations, user management, CRM verification, and team reports.
CRM / Manager Can be enabled later through Calling Center permissions. No access unless permissions are assigned.

MCube Integration

Calling Center uses the existing MCube outbound service. Every campaign call stores an outbound attempt with request payload, response payload, status, and error message when available.

Ref ID format:

calling_campaign:{campaign_id}:item:{item_id}

When MCube sends a webhook with this ref ID, CRM links the call status and call log back to the campaign item.

Reports

Campaign Report

Total, pending, completed, failed, skipped, and outcome counts.

Agent Report

Attempted calls, connected calls, talk time, average duration, and outcomes.

Call Detail

Lead, phone, status, call log, MCube attempt, duration, and recording URL.

Testing Checklist

  • Run migrations and confirm the Telecaller role exists.
  • Configure MCube outbound token and API URL.
  • Create a telecaller user with a valid phone number.
  • Create a campaign from Lead Bank and start it.
  • Confirm MCube outbound attempt is created.
  • Open My Calling Queue and submit an outcome.
  • Confirm counters update and the next call starts after delay.
  • Confirm duplicate or blocked leads are skipped.
  • Export the campaign report and verify call details.
